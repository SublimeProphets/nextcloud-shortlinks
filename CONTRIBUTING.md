# Contributing

Open an issue before large behavioural or schema changes. Keep changes focused, add tests for failure and authorisation paths, update OpenAPI/user/admin/privacy docs, and run the commands in `docs/testing.md`.

Use English for code and source strings, add the matching German translation, apply SPDX headers to new source files, and preserve the public `OCP\\` boundary. Never edit a released migration or include real personal data, secrets, MMDB databases or generated credentials. Security reports follow `SECURITY.md` rather than a public issue.

Commits should be reviewable and signed off where the project host requires it. By contributing, you agree that your contribution is licensed under AGPL-3.0-or-later.
