# User guide

Open **Shortlinks** from the Nextcloud navigation. **New short link** requires a target whose URL scheme is enabled by the administrator; HTTP(S) is enabled by default. The alias is optional. Choose folder, tags, redirect type, access mode, time window and click limit. Tags can be created directly in the form. When the administrator enables protected title fetching, **Fetch title** can fill the title for public HTTP(S) targets without blocking manual entry. A password is accepted only for password mode and is never shown again.

Open **Settings → Aliases and sharing URLs** in the app navigation to choose a personal default. Aliases can remain administrator-managed, be random, or be derived from the link title/destination. Readable collisions can receive the shortest configured random suffix or ascending `-2`, `-3`, … suffixes. If enabled by the administrator, the copied URL can inherit the global format, append the alias to a personal domain, use `{alias}`/`{user}` placeholders, or apply a regular-expression replacement. A custom domain must already route requests to the Shortlinks redirect endpoint.

Use the left navigation for the dashboard, all links, favourites, recent, inactive, expired, trash, folders and tags. The fixed content toolbar shows the current view as switchable breadcrumbs. Its search can combine text with creation age and active state; the tag menu supports AND/OR matching. Sort a list directly from the title, alias, click or date table headings. Export and import are grouped in the toolbar, while selection exposes bulk changes. **Statistics** summarises the account's own links. Open a row for target, hourly/daily/weekly/monthly statistics, comparison, the paginated privacy-reduced click log, activity and shares; recipient search uses current Nextcloud users/groups. Charts are represented by accessible tables. Copy either URL from the row actions. QR codes are generated locally.

Folder nesting is limited to ten levels. Deleting a folder can keep its links (they become unfiled) or move them to trash. A share grants another Nextcloud user/group management view or edit access; it does not silently change public redirect access.

Trash is recoverable until administrator retention cleanup. Permanent deletion is available only after trashing. CSV/JSON import supports dry-run and either skip-conflict or generate-new-alias behaviour, including nested folder paths, tags, lifecycle values and available YOURLS history. Exports apply the current search/folder/tag/status filter and include only links visible to the current account.

Open **Settings → Bookmarklet** to install a draggable browser bookmark. It opens the current page in Shortlinks with its URL prefilled, so a link can be created without copying the address manually.

Use 302 (default) or 307 if destinations/policies may change. 301/308 can be cached outside Nextcloud, making later edits and analytics incomplete. Administrators may enable additional 3xx codes; client behaviour for non-standard codes can vary.
