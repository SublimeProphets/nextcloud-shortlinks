# Security policy

Security fixes are supported for the latest Shortlinks release on supported Nextcloud/PHP versions.

Report vulnerabilities privately to the future repository's security-advisory channel or maintainer security address. Because those release contacts are not yet known, do not deploy this unsigned development snapshot as a public service until a private reporting address is published. Do not include real tokens, passwords, full URLs containing secrets, IP addresses or database dumps. Include affected version, impact, minimal reproduction and suggested mitigation.

Maintainers should acknowledge within 7 days, triage privately, coordinate a fix/advisory and credit the reporter if desired. Do not create a public issue before a fix is available.
