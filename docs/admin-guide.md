# Administrator guide

Enable the app with `occ app:enable shortlinks`, configure system cron, then review **Administration settings → Shortlinks**. The safest baseline is random seven-character aliases, public creation off, HTTP(S) only, title fetching off, statistics with DNT/GPC respected, domain-only referrers, authenticated-user logging off and admin-wide management off.

Domain rules are exact names or `*.example.org` subdomain rules. Blocklist wins over allowlist. The shared short-link URL can use a simple HTTP(S) base URL, an `{alias}`/`{user}` template, or a regular-expression replacement of the canonical Nextcloud route. Custom domains must be served by a trusted reverse proxy that forwards the generated path to Shortlinks; the setting does not configure DNS or proxy routing. Administrators can allow or forbid per-user alias and URL overrides. Store a GeoLite2-compatible `.mmdb` locally; the file is not bundled. Check it with `occ shortlinks:geoip:check`.

Administrators can add URI schemes such as `mailto` or `webcal`. Schemes are normalized to lowercase; intrinsically unsafe browser schemes such as `javascript`, `data`, and `file` are rejected. Domain rules apply only when a target contains a host, and protected server-side title fetching always remains limited to public HTTP(S) targets. Redirect status codes can be selected from the defaults or added in the 300–399 range. Non-standard 3xx codes are allowed for controlled integrations but may not be followed consistently by every client.

Set retention values and run cron at least every five minutes. The settings page can aggregate today/yesterday, run retention cleanup, or rebuild up to 365 recent days; these actions are admin-only and audited. For automation use `occ shortlinks:health`, `shortlinks:stats:aggregate`, `shortlinks:stats:cleanup`, `shortlinks:stats:rebuild`, `shortlinks:import`, `shortlinks:export`, `shortlinks:owner:transfer`, and `shortlinks:seed --user=<uid>`. Owner transfer is the explicit offboarding path; choose a successor before deleting an account. Conflicting tags are merged and conflicting root-folder names receive a `(transferred)` suffix atomically.

Public creation is an off-by-default, rate-limited endpoint and requires a dedicated existing owner UID. An empty public-creation group list allows guests; a configured list restricts it to signed-in members, so an upstream abuse-control policy is still required for internet exposure. YOURLS credential-in-URL compatibility, JSONP and custom personal-token authentication are intentionally not exposed. External automation should use the authenticated OCS API with a Nextcloud app password. The legacy/token configuration keys and token schema are reserved for separately reviewable future compatibility work; no custom authentication bypass is active.

Monitor `nextcloud.log` for messages tagged `shortlinks`, cron status and database growth. Back up app tables and app configuration with the normal Nextcloud/database procedure. Never place the visitor secret, password hashes or API credentials in support bundles.
